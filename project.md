# Wedding Invitation Project

## Project Overview
This project is a modern wedding invitation website created for Nuwan and Tharushi. The site is designed as a romantic, elegant digital invitation that can be shared with guests online. It combines a premium visual design, smooth animations, multilingual support, countdown, and RSVP functionality.

## Work Completed

### 1. Homepage and Invitation Design
- Built a full landing page for the wedding invitation
- Added a luxury, romantic visual theme with burgundy, gold, ivory, and soft floral-inspired styling
- Created a hero section with names, date, and invitation tagline
- Designed elegant typography and spacing for a polished wedding aesthetic

### 2. Preloader and Intro Experience
- Added a preloader screen before the main invitation opens
- Included a “Open Invitation” button to reveal the full site
- Added smooth transitions for a premium feel

### 3. Multi-Section Wedding Layout
- Created sections for:
  - Story
  - Event details
  - Family blessings
  - Gallery
  - RSVP
- Used clear visual sections with numbered headings for a structured invitation flow

### 4. Countdown Timer
- Added a live countdown to the wedding date
- Countdown updates every second until the event date

### 5. Gallery and Lightbox
- Added wedding image gallery cards
- Implemented click-to-open lightbox/modal for enlarged photos
- Included responsive image layout across desktop and mobile devices

### 6. RSVP Functionality
- Built an RSVP form for guest responses
- Added a WhatsApp submission flow so guests can send RSVP details directly
- Included guest count and optional message fields

### 7. Calendar and Share Features
- Added “Add to Calendar” support to generate an .ics file
- Added “Share invitation” feature using the browser share API or copied link fallback

### 8. Language Support
- Added bilingual content in English and Sinhala
- Included a language toggle switch for easy switching
- Stored the selected language in local storage for persistence

### 9. Responsive Design
- Designed the site to adapt smoothly for desktops, tablets, and mobile devices
- Adjusted layout and navigation behavior for smaller screens

### 10. Accessibility and Interaction Enhancements
- Included ARIA labels for major elements
- Added interactive mobile menu behavior
- Added toast notifications for user feedback
- Utilized scroll reveal animations for subtle modern effects

## Project Structure

- index.html — main page structure and content
- css/style.css — styles, layout, colors, animations, responsiveness
- js/app.js — interactivity, countdown, language switch, RSVP, gallery, sharing, and calendar features
- images/ — project photos and visuals

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Fonts
- Browser APIs such as navigator.share, localStorage, and IntersectionObserver

## Features Included
- Elegant digital wedding invitation page
- Countdown to the event date
- Story and relationship timeline section
- Event venue and schedule details
- Photo gallery with modal viewer
- RSVP form with WhatsApp sharing
- Add-to-calendar option
- English and Sinhala language toggle
- Responsive mobile-friendly layout

## Notes
This website is prepared as a complete online wedding invitation experience and is suitable for sharing with guests through a browser or social media. The project is designed to be visually appealing, functional, and easy to maintain.
